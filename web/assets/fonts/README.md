# Metrics Map fonts

Bundled 25 September 2026 for offline rendering of `campaign-01_metrics-map.html`.

`metrics-map.css` references local TTF files. `metrics-map-google.css` preserves the original Google Fonts response and precise download URLs. Font binaries are unchanged.

Families/weights: Manrope 700/800; IBM Plex Sans Thai 400/500/600; IBM Plex Mono 400/500.

Source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Manrope:wght@700;800&family=IBM+Plex+Sans+Thai:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap), with binary URLs under `fonts.gstatic.com`.
