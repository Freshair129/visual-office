# Zuri head correction after rejected MPFB pilot

Authority: owner's `fix it` following explicit rejection of the pilot comparison.
The approved Zuri sheet remains the art reference. This is a scoped implementation
plan, not new character design approval.

## Failure and correction

The pilot has protruding spherical eyes, heavy lips, an exposed cylindrical neck
and a continuous helmet-like fringe. Its functional checks did not establish art
quality. Preserve it as rejected evidence; never describe it as accepted.

1. Build a separate, editable head with a deliberately shaped cheek/jaw profile,
   shallow almond eye openings and enclosing lids, small mouth and nose, and a
   short neck seated into the existing collar. Do not stretch the MPFB face again.
2. Replace the inherited hair with parted overlapping locks, tapered fringe and
   a rounded bob silhouette. Retain brown hair, amber clip and fine round glasses.
3. Render front, three-quarter, profile and back before exposing the revision in
   Character Lab. Inspect these images against the approved sheet. Correct visible
   failures instead of using polygon/test counts as a visual approval.
4. Export a new GLB and Blender source. Preserve rejected/current files unchanged.
   The `blender` Lab entry loads the corrected candidate; a labelled rejected
   version supports same-camera comparison. Static head work advertises no clips.
5. Reopen exported geometry, check the new surfaces, run Lab/asset regressions and
   build, then test the actual synthetic Worker browser. Record actual limits.

No floor adoption, provider generation, live calls, agent identity/role changes,
staff edits or Wangjai edits. Body/clothing remain fitting references this round.
