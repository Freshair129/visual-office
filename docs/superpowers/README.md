# Dated design and delivery records

[Documentation home](../README.md)

- [Design/specification index](specs/README.md): links to historical design records.
- [Implementation-plan index](plans/README.md): links to historical plans and plans awaiting owner disposition.

The current SRS, architecture and design sources take precedence for today's product/system description. These dated records retain their original approval and evidence context. A checked task or test count in an old plan is not a fresh acceptance result, and this directory does not assign Zuri API or Agent authority.

Keep one dated record per existing scope; update this family's indexes when a record is added or moved. No current/ folders were created because no dated record was assigned there. The docs checker verifies that each record is indexed.
