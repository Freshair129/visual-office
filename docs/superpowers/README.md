# Dated design and delivery records

[Documentation home](../README.md)

- [Design/specification index](specs/README.md): dated implementation designs and art prompts.
- [Implementation-plan index](plans/README.md): task sequencing and recorded verification boundaries.

The current [SRS](../VISUAL-OFFICE-SRS.md), [architecture](../ARCHITECTURE.md) and
[design sources](../DESIGN-SOURCES.md) take precedence for today's product/system
description. These dated records retain their original approval and evidence
context. A checked task or test count in an old plan is not a fresh acceptance
result, and the directory does not assign Zuri API or Agent authority.

Keep one dated record per existing scope; update this family's indexes when a
record is added or moved. `npm run docs:check` verifies that each record is indexed.
