## Art direction

สำนักงานจำลองแบบ mobile office idle ที่ดูอบอุ่นและใช้งานง่าย: รูปทรงอ่านได้ชัด ขอบมนเล็กน้อย ไม้และผนังครีม แสงอำพัน กระจกฟ้า และต้นไม้เขียว ใช้โทนเดิมจาก `web/assets/office-world/lobby-desktop.png` และ campus ที่มีอยู่

สีหลักของแบรนด์: Amber Citrus `#E8820C`, Brand Tint `#FDE8D0`, Rest Blue `#D6ECFA` ผสมวัสดุไม้ ครีม และ sage-green ของเฟอร์นิเจอร์ ไม่สร้างภาพอุปกรณ์อัปเกรดที่สื่อว่าแรงประมวลผล agent เพิ่ม

มุมกล้องหลักเป็น orthographic isometric ประมาณ 35 องศาก้ม ปรับมุมเล็กน้อยได้ ฉากต้องอ่านเป็นทรงเดียวกันทั้ง desktop และ portrait ไม่มีข้อความสำคัญฝังอยู่ในภาพ

## Starter slice: ชุดแรกที่แนะนำ

ห้องทดลองหนึ่งห้อง ไม่ระบุ domain พร้อมสิ่งต่อไปนี้:

| ชิ้นงาน | รูปแบบ | จุดที่ต้องคงเดิม |
| --- | --- | --- |
| ห้อง | Compact / Open studio / Lounge wing | ประตูและจุดเชื่อมลิฟต์ |
| โต๊ะ | Starter / Studio / Signature | จุดนั่ง พื้นที่ interaction และจุดวางชื่อ |
| เก้าอี้ | 3 ระดับ | ระดับเบาะและท่านั่ง |
| ผนัง/พื้น/ไฟ | 3 ชุดวัสดุ | ขอบเขตห้องและทางเดิน |
| ของชิ้นเล็ก | ต้นไม้ โคม พรม ตู้ ชั้นวาง | ขนาดช่องและจุดหมุน |
| ตัวละครทดสอบ | mannequin กลาง 1 ตัว | ท่ายืน เดิน นั่ง; ไม่มี role จริง |

ใช้จำนวนโต๊ะเปลี่ยนได้ ตัวอย่างสี่โต๊ะใน concept board มีไว้เทียบความสวยระหว่างระดับเท่านั้น

## Modular geometry

- ใช้หน่วยเมตรเป็น convention สำหรับ asset และกริดประกอบช่วง 0.5/1 เมตร
- root อยู่ที่พื้น; แกนตั้ง Y; ใช้ข้อตกลงเดียวกันทุกชิ้น
- ทำชิ้นผนังตรง มุม หน้าต่าง และประตูให้ต่อกันได้
- Furniture มีจุดอ้างอิงสำหรับวางบนพื้น นั่ง และแสดงป้าย; จัดทำภาพ guide ก่อน export
- ส่วนเติบโตของห้องต่อด้านข้าง ไม่ทำให้ตำแหน่งประตูและลิฟต์เปลี่ยนโดยไม่มี transition
- ป้าย Business/domain/floor ใช้ข้อความใน UI หรือป้ายที่เปลี่ยนค่าได้ภายหลัง
- ซ่อนผนังด้านหน้าตามมุมกล้องได้โดยไม่ตัดของด้านใน
- ชุดหน้าตึกแยกฐาน / ชั้นซ้ำ / หลังคา / ปีกอาคาร / สวน

## การแสดงสถานะ

Ambient animation เช่นเดินในสวนหรือดื่มกาแฟเป็นเพียงชีวิตในฉาก การแสดง agent ว่ากำลังคิด กำลังทำงาน รอตรวจ หรือมีปัญหาต้องรับสถานะจริงในอนาคต

อย่าใช้การเดินถึงโต๊ะเป็นเหตุให้ระบบถือว่างานเริ่ม และอย่าใช้ท่าฉลองเป็นเหตุให้ถือว่างานเสร็จ

โหมดแสดงโมเดลระหว่างรอ platform ใช้ป้าย “ฉากทดลอง” และเลือกท่า animation ด้วยมือได้ ไม่มีผลกับ Business

## งบด้านประสิทธิภาพสำหรับเริ่มทดลอง

ตัวเลขต่อไปนี้เป็นเป้าทำต้นแบบ ต้องวัดและปรับจากอุปกรณ์จริง:

- 30 FPS บนเครื่องมือถือเป้าหมาย และ 60 FPS บน desktop เป้าหมายในห้องเดียว
- แสดงฉาก 3D รายละเอียดสูงทีละชั้น; ชั้นอื่นใช้ LOD หรือไม่ render
- ทดลองเริ่มที่ไม่เกินประมาณ 80,000 triangles และ 100 draw calls สำหรับฉากห้องที่มองเห็นบน mobile
- แชร์ geometry/material ของเฟอร์นิเจอร์ซ้ำ; จำกัดจำนวนเงา real-time และแสงที่มีผลพร้อมกัน
- วัสดุส่วนใหญ่ใช้สีและ texture atlas; ไม่ส่ง texture 4K ทุกชิ้นโดยไม่มีเหตุผลด้านภาพ
- หยุด animation/render ที่ไม่จำเป็นเมื่อออกจากหน้า; ต้องถอด asset pack แล้วคืนทรัพยากรได้
- ปุ่มและรายการใน UI ใช้ได้แม้ WebGL ไม่พร้อม; ลด motion และปิดเสียงได้

ไม่ใช้ผล benchmark จาก model viewer แทนการทดสอบใน Office จริง

## ชุดส่งมอบต่อ asset

ไฟล์ต้นฉบับที่แก้ได้, ไฟล์ GLB, texture ที่จำเป็น, ภาพ preview, รายการ dimensions/anchors/materials/animations และที่มาของสิทธิ์ใช้งาน แต่ละ variant ต้องเทียบตำแหน่งได้โดยไม่ต้องแก้ข้อมูล Zuri

ตัวอย่างชื่อสำหรับงานศิลป์เท่านั้น:

`desk-starter`, `desk-studio`, `desk-signature`, `room-compact`, `room-lounge-wing`, `wall-window`, `lift-bay`, `lobby-reception`, `tower-floor-repeat`

ชื่อเหล่านี้เป็นชื่อ asset ไม่ใช่ entity ID, domain key หรือ API contract

## ตรวจรับก่อนนำเข้าฉากหลัก

1. วาง variant ทั้งสามที่ตำแหน่งเดียวกันแล้วจุดนั่งและป้ายไม่กระโดด
2. แอนิเมชันนั่งไม่ทะลุโต๊ะหรือเก้าอี้ในแต่ละระดับ
3. ห้อง Compact และ Lounge wing ใช้ประตู/ลิฟต์เดิมได้
4. มุม portrait ยังเห็นเส้นทางและแตะของสำคัญได้
5. ลอง 0, 1, 4, 12 และ 40 ตัวละครจำลองโดย UI รายชื่อไม่ทำข้อมูลหาย
6. สถานะ decoration ไม่แสดงเป็นงานสำเร็จหรือ agent ออนไลน์
7. วัด FPS, memory และ asset load บนอุปกรณ์ที่ระบุชื่อได้
8. เก็บภาพก่อน/หลังและผลวัดพร้อมรุ่นของ asset ที่ตรวจ
